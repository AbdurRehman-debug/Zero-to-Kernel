# Daily Log 📓

This folder documents every single day of my journey from SE student to Kernel Engineer.

One markdown file per week. Every day gets an entry inside that week's file.
No skipping days. No exceptions. No "I was busy."

---

## daily-log vs notes — Not the Same Thing

This repo has two writing systems. They serve different jobs on purpose:

```
daily-log/              →  process. Written the SAME DAY, in the moment.
                            Messy is fine. Confusion is fine. This is a diary.

phase-X/.../notes/      →  reference. Written ONLY once a topic is fully
                            understood. Clean, distilled, no confusion left
                            in it. This is a wiki entry, not a diary entry.
```

If an entry here in daily-log reads like a polished explanation with no
rough edges — that is a sign it should have been shorter, and the polished
version belongs in the phase's `notes/` folder instead, written later.

---

## Why Log Every Day?

**Problem 1 — Passive learning feels like progress but isn't.**
Watching a video and nodding along is not learning. Writing what you
understood in your own words immediately reveals the difference between
actually understanding something and just recognizing it.

**Problem 2 — Progress is invisible day to day.**
On Day 47 you will feel like you have learned nothing. Reading back through
Days 1-46 proves that wrong.

**Problem 3 — No accountability.**
A public log on GitHub is a public commitment. Every day without an entry
is visible to anyone who looks.

---





## The Rules

**Rule 1 — Write the same day.** Not the next morning.

**Rule 2 — Be specific.** Name the exact video, chapter, page numbers.

**Rule 3 — Your own words only.** No copying, no paraphrasing from source.

**Rule 4 — Log bad days too.** 30 minutes because of university work? Log it.
Nothing made sense? Log that too. Honesty matters more than a perfect streak.

**Rule 5 — Never delete.** Even the entries where you misunderstood something
basic. Those are the most valuable to read back later.

**Rule 6 — Minimum one entry per day.** Even on exam days. A 3-line entry
beats no entry.
